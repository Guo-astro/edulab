# 讲解指南（老师讲解型）

## 结构：每一小问

1. **审题**（1 句）：用自己的话复述条件，点出关键条件。不写板书或只高亮图形。
2. **找思路**（1～2 句）：讲"为什么会想到这样做"——由结论倒推需要什么、由条件联想到什么定理。配一个 `tip` 把方法挂出来。
3. **板书推理**（每步 1 句 + 1～2 行板书）：口播解释，板书只写规范步骤（∵ ∴ ⇒）。图形动作与口播同步（`at` 锚点）。
4. **结论**：结论行 `!!…!!` + `emph`。
5. **小结**（1 句）：一般方法 / 易错点，配 `tip`，视角转回 `home`。

## 分学段口吻

| 学段 | 语速 speechRate | 口吻 | 板书 |
|---|---|---|---|
| 小学 | -10 | 亲切、多用"我们""你发现了吗"，每步都说清楚为什么 | 少符号，多文字；可用"第一步/第二步" |
| 初中 | -5 ～ 0 | 清楚、强调定理名称 | 标准推理格式，定理名括注 |
| 高中 | 0 | 简洁、突出思路与方法迁移 | 规范符号，省略显然步骤 |

## 句子与板书长度

- 一句口播 15～45 字。太长就拆成两个 beat（字幕按标点自动分行，每行 ≤ 26 字）。
- 一行板书 ≤ 22 个汉字宽（含公式）；check 报 `overflow-x` 必须拆行。
- 板书里的公式用 LaTeX `$…$`（见 lesson-schema.md 的"公式"一节），不要用 `√`、`²`、`/` 等纯文本符号拼。
- 一个小问板书 5～8 行最佳；超过一页会自动翻页，但尽量在一页内讲完一个逻辑段。

## 口播文本（say / speak）

- `say` 是字幕，可以写 `BC₁`、`∠DEF`、`45°` 等符号；默认会自动转成朗读文本：字母逐个读（"B C 1"），`∥` 读"平行于"，`⊥` 读"垂直于"，`△` 读"三角形"。
- 读法不自然时写 `speak` 覆盖，例如：分数 `"speak": "二分之一"`、根式 `"speak": "根号三"`、负数、区间、上标。
- 多音字/生僻字：构建输出的 `warnings` 里出现 `读音未固定` 时，直接在 `say` 里给该字标音 `长[cháng]`（字幕和锚点会自动去掉标注；标注写在字**后面**，规则同 [../../reference/pronunciation.md](../../reference/pronunciation.md)），或把词加进 `pron.json`。
- 不要在 `say` 里放 `$...$`（朗读会被丢弃）；需要时写 `speak`。

## 锚点（at）技巧

- 锚点写口播中**确实出现**的词，越短越稳："连接"、"DE"、"平面"、"所以"。
- 同一个词出现多次时匹配第一次；需要后面的就选更独特的词或用 `delay`。
- 板书行通常锚在引出它的词上；没有合适的词就不写 `at`，按顺序排布。

## 空间想象题

- 关键关系（平行、垂直、射影）讲到时转动视角：`{"cam": "face", "target": [平面四点]}` 让该平面正对观众；讲完 `{"cam": "home"}`。
- 一次只突出 1～2 条关键线；上一问的高亮面在下一问开头 `hide` 掉。
- 每个新视角都加 `tag`，让学生知道"现在从哪个方向看"。
