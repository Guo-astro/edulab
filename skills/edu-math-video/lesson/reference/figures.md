# 图形组件

三种 `figure.type` 共用同一套动作（seg / poly / dot / label / par / rt / angle / text / point），区别在坐标与视角。

## solid3d（立体几何，可旋转）

```jsonc
"figure": {
  "type": "solid3d",
  "points": { "A": [2,0,0], "B": [0,2,0], "C": [0,0,0], "A1": [2,0,2], "B1": [0,2,2], "C1": [0,0,2] },
  "faces": [["A","B","C"], ["A1","B1","C1"], ["A","B","B1","A1"], ["B","C","C1","B1"], ["A","C","C1","A1"]],
  "extra": [{ "name": "D", "mid": ["A","B"] }, { "name": "E", "mid": ["A","C1"] }],
  "given": [["A","C1"], ["D","E"]],          // 题目图中已有的非棱线段
  "marks": [{ "op": "rt", "v": "C", "a": "A", "b": "B" }],
  "camera": { "home": { "az": 235, "el": 24 } },   // 初始视角（度）
  "zoom": 0.8                                 // 可选，图在区域内的占比
}
```

- **faces 必须列全**（凸多面体的所有面，顶点按环绕顺序）。棱由面自动生成；虚实线据此每帧计算：线段在朝向观众的面上为实线，否则为虚线；穿过内部的线段（如 DE）恒为虚线。
- **坐标约定**：z 轴向上；`az` 是相机视线的水平方向角（从 +x 轴起逆时针，度）。以 C 在原点、A 在 x 轴、B 在 y 轴为例，225°～235° 就是课本常见视角（A 在左前、B 在右前、C 在后）；`el` 是俯视角（20°～30° 最自然）。
- 中点用 `mid`，其他点用坐标；`extra` 里的点在开头就显示，`{"fig":"point"}` 动作中的点在讲到时才出现。
- 视角动作：`face`（自动选角，优先正对目标面、点不重叠、转动量小）、`view`、`spin`、`home`。lab 风格会叠加 ±10° 的缓慢摆动。
- 标签自动放在离所有线段最远的方向；挤的时候换 `home` 角度或减少同时显示的线。

## plane2d（平面几何）

```jsonc
"figure": {
  "type": "plane2d",
  "points": { "A": [1.2, 3.2], "B": [0, 0], "C": [4, 0] },
  "edges": [["A","B"], ["B","C"], ["C","A"]],
  "extra": [{ "name": "M", "mid": ["A","B"] }],
  "given": [["A","M"]],
  "marks": [{ "op": "rt", "v": "B", "a": "A", "b": "C" }]
}
```
y 轴向上；没有虚实线计算（需要虚线用 `"dash": true`）。

## graph（函数 / 坐标系）

```jsonc
"figure": {
  "type": "graph",
  "view": { "xmin": -2, "xmax": 4, "ymin": -1, "ymax": 7 },
  "tick": 1,                         // 刻度间隔
  "equalAspect": true,               // false 时 x、y 各自缩放填满区域
  "points": { "P": [1, 2] },         // 数据坐标
  "labels": false,                   // 开头不自动显示点标签
  "curves": [{ "f": "x^2-2*x+3", "role": "given" }]   // 开头就画的曲线（可省略）
}
```
- 坐标轴、刻度、原点 O 自动绘制；曲线用 `{"fig":"curve","f":"…"}` 动作逐段画出，超出 `view` 的部分被裁掉。
- 表达式：`^` 乘方，可用 `sin cos tan sqrt abs log ln exp PI` 等。
- 对称轴、渐近线：先用 `point`（`"show": false`）定义两个端点，再画 `seg` + `"dash": true`。

## 角色（role）→ 各风格颜色

| role | 含义 | chalk | lab | whiteboard | notebook |
|---|---|---|---|---|---|
| edge | 棱/原图线 | 白 | 灰 | 蓝 | 黑 |
| given | 题中已有线段 | 白(细) | 灰(细) | 蓝(细) | 黑(细) |
| aux | 辅助线 | 蓝 | 青(发光) | 绿 | 蓝 |
| key | 关键线 | 黄(粗) | 金(发光) | 红(粗) | 橙(粗) |
| tri / plane / plane2 | 高亮面 | 黄 / 蓝 / 粉 | 金 / 青 / 红 | 黄 / 绿 / 红 | 黄 / 蓝 / 粉 |
